# 호수중 브롤 (hosu-brawl)

브롤스타즈풍 실시간 온라인 대전 (Node.js + socket.io). 지금은 캐릭터 1명: **정보쌤**.

## 로컬 실행
```
npm install
npm start      # http://localhost:3000
```

## Render 배포
1. 이 폴더를 GitHub 저장소로 push
2. Render → New → Web Service → 저장소 선택
3. Build: `npm install` / Start: `npm start`
4. 나온 주소를 친구한테 공유 → 접속하면 모두 같은 로비에서 대전

> GitHub Pages는 서버를 못 돌려서 안 됨. 서버가 필요함 (Render / EC2 등).

## 조작
PC: WASD 이동, Space/클릭 공격, Q·E 가젯 · 폰: 왼쪽 조이스틱 + 오른쪽 버튼

## 브롤러 추가하는 법
1. `brawlers.js`에 새 브롤러 데이터 추가 (이름, 등급, 체력, 공격/가젯/궁극기 수치)
2. `server.js`의 `SKILLS`에 같은 id로 attack / gadget / super 함수 추가
3. `public/index.html`에서 3D 모델 함수 만들고 `MODELS`에 등록
→ 로비의 브롤러 화면에 자동으로 카드가 생김

## 모드 (modes.js)
- 쇼다운 3종 (`mode.sd`): 솔로 `showdown`(10명) · 듀오 `duo`(10명, `squad: 2`) · 트리오 `trio`(12명, `squad: 3`). 팀 = `p.team`(0~), `assignSquads`로 짜고 `isEnemy`가 같은 팀은 안 때림.
  - 죽으면 `sdEliminate`: 살아 있는 팀원이 없는 팀만 탈락(등수 = 남은 팀 수 + 1). 듀오·트리오는 그 전까진 `squadRespawn`(15초) 뒤 팀원 옆에서 부활.
  - 파워 큐브: 큐브 상자(`ROBOTS.pbox`, struct + `box`)를 부수면 `room.cubes`에 1개. 1개당 최대 체력·피해 +10% (`mhp(p)`, `p.cubeHp`). 죽으면 다 떨어뜨림.
  - 맵: `SD_MAPS`를 `SD_SCALE`(1.45)배로 넓히고 엄폐물 추가. 트로피 `SD_TRO` = 10/7/5/2/0, 6등부터 패배. 4등까지 연승 +1, 5등 유지.
| 모드 | 내용 | 맵 |
|---|---|---|
| ⚔️ 난투 | 개인전, 3초 부활, 4분마다 맵 변경 | 컴퓨터실 · 수학실 · 급식실 |
| 💀 쇼다운 | 6인 생존전, 부활 없음, 보라색 독가스가 좁혀옴 | 운동장 · 체육관 |
| 💎 젬 그랩 | 3대3, 보석 10개 모아 15초 버티면 승리 (3분 제한) | 수학실(젬) · 급식실(젬) |

## 로그인 / 계정 저장
- 닉네임 + 비밀번호로 가입 (비밀번호는 scrypt 해시로만 저장). 게스트로도 플레이 가능(트로피 저장 안 됨).
- 로비 오른쪽 트로피 순위표(세로 폰은 🏆 순위 버튼) → 이름 누르면 플레이어 프로필(트로피·최고 트로피·전적·대표 브롤러·브롤러별 트로피). 내 프로필에서 아이콘(브롤러 얼굴) 변경 → `prefs.icon`. 소켓 `players` / `profile`.
- 매칭: 라운드 모드(젬·쇼다운·하이스트·브롤볼·현상금·녹아웃)는 대기실(`phase: 'queue'`, 방 id `모드[@맵]#q…`)에서 사람을 기다림 → 꽉 차거나 「바로 시작」(`startNow`)이나 60초 → 빈자리 봇. 판 끝나면 다시 대기실. 난투·더블가젯은 공용 방, 시간 제한 없음(4분마다 맵 변경), 처치 트로피. 봇 난이도 `botLv(room)`: 사람들 브롤러 트로피 평균/1500으로 BOT_EASY↔BOT_HARD 보간.
- 결과 화면: `endRound`가 `result.stats`(처치·데스·준 피해 `dealt`)와 `result.star`(이긴 쪽 점수 = 처치×3 + 피해/1500 − 데스×1.5 최고)를 보냄 → 클라 `showResult`.
- 결과 화면 포즈: 카드마다 `<canvas class="pz">` + 렌더러 하나 돌려쓰기 (`poseStart`). 브롤러별 승리/패배 동작은 `PANIM[id].win/lose(P, t, o)` (t=초, `o.txt`/`o.emo`/`o.bubble`/`o.num`은 2D로 위에 그림). 새 브롤러는 `PANIM`에 추가 (없으면 기본: 점프 / 고개 숙임).
- 연승: `auth.setStreak` (계정당 `u.streak`). 이기면(쇼다운 1등) +1, 지면 0 → n연승이면 n-1(최대 10) 추가 트로피. 난투·더블 가젯 제외. `trophy` 이벤트에 `streak`, `bonus`.
- 트로피는 서버가 직접 지급, 브롤러별(`bt`). 팀 모드는 브롤스타즈 2026 트로피 3.0 표(`TRO_3V3`: 0~1999 승 +10, 패 0→-10, 2000부터 승 감소, 4000+ -15), 쇼다운은 솔로 쇼다운 표(`TRO_SD`, 6명→10등 환산), 무승부 0. 프레스티지: 브롤러별 최고 트로피(`bbest`)의 1000 단위 아래로 안 떨어짐. 브롤러 등급(클라 `tierOf`): 우드 0 · 브론즈 250 · 실버 500 · 골드 750 · 프레스티지 N = 1000×N. 쇼다운은 탈락 즉시 반영. 난투·더블가젯만 사람끼리만 처치 +1, 사망 −1(100+)/−2(500+) (봇이 낀 킬은 제외). 게임 중 나가면 패배. 친선전·훈련장 제외. 총 트로피 = 브롤러별 합 + 업데이트 전 트로피(`legacy`).
- **Render 환경변수 꼭 설정**: 무료 서버는 재시작하면 디스크가 지워져서 계정이 사라짐.
  - `GIST_ID`, `GIST_TOKEN` — 골목대전 서비스에 있는 값 그대로 복사해도 됨 (저장 파일 이름이 `jungbo-brawl.json`이라 안 섞임)
  - 설정 안 하면 `data/db.json`에만 저장 (재시작 시 초기화)

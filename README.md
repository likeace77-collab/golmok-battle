# 정보쌤 브롤

브롤스타즈풍 실시간 온라인 대전 (Node.js + socket.io). 지금은 캐릭터 1명: **정보쌤**.

## 로컬 실행
```
npm install
npm start      # http://localhost:3000
```

## Render 배포
1. 이 폴더를 GitHub 저장소로 push
2. Render → New → Web Service → 저장소 선택
3. Build: `npm install` / Start: `npm start`
4. 나온 주소를 친구한테 공유 → 접속하면 모두 같은 로비에서 대전

> GitHub Pages는 서버를 못 돌려서 안 됨. 서버가 필요함 (Render / EC2 등).

## 정보쌤 (3D: 뚱뚱한 체형, 뿔테안경, 금목걸이, 검은 티·검은 외투, 하늘색 바지)

## 스킬
| | 이름 | 효과 |
|---|---|---|
| 기본공격 | 아~ 이놈의 아이들 | 재키처럼 주변 150 범위 1000 데미지, 탄 3개 |
| 가젯1 (Q) | AI야? 시키지도 않은 걸 하네 | 주변 260 범위 1.6초 스턴 + 300 데미지 |
| 가젯2 (E) | 마우스 소환 | 마우스 2마리 소환, 8초 동안 적 쫓아가 260씩 딸깍 |
| 궁극기 (R/우클릭) | 이놈의 아이들 | 부채꼴 강공격 2200 + 넉백. 기본공격 맞히면 충전 |

가젯: 무제한, 공용 쿨타임 6초. 체력 4200, 3초간 안 맞으면 회복.
수치 조절은 `server.js` 맨 위 `C` 객체에서.

## 조작
PC: WASD 이동, Space/클릭 공격, Q·E 가젯 · 폰: 왼쪽 조이스틱 + 오른쪽 버튼

## 브롤러 추가하는 법
1. `brawlers.js`에 새 브롤러 데이터 추가 (이름, 등급, 체력, 공격/가젯/궁극기 수치)
2. `server.js`의 `SKILLS`에 같은 id로 attack / gadget / super 함수 추가
3. `public/index.html`에서 3D 모델 함수 만들고 `MODELS`에 등록
→ 로비의 브롤러 화면에 자동으로 카드가 생김

## 로드아웃
가젯 1개 · 스타파워 1개 · 기어 2개(6개 중). 브롤러 화면 → 브롤러 카드에서 선택.

## 로그인 / 계정 저장
- 닉네임 + 비밀번호로 가입 (비밀번호는 scrypt 해시로만 저장). 게스트로도 플레이 가능(트로피 저장 안 됨).
- 트로피는 서버가 직접 지급: 처치 +1, 승리 +8. 선택한 브롤러·모드·로드아웃도 계정에 저장.
- **Render 환경변수 꼭 설정**: 무료 서버는 재시작하면 디스크가 지워져서 계정이 사라짐.
  - `GIST_ID`, `GIST_TOKEN` — 골목대전 서비스에 있는 값 그대로 복사해도 됨 (저장 파일 이름이 `jungbo-brawl.json`이라 안 섞임)
  - 설정 안 하면 `data/db.json`에만 저장 (재시작 시 초기화)

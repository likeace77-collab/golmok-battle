# 골목대전

친구와 둘이서 하는 턴제 요괴 배틀 웹게임입니다. 서버 한 대를 켜 두면 둘 다 브라우저(폰 포함)로 접속해서 플레이합니다.

## 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

`http://localhost:3000` 으로 접속합니다.

## 친구와 같이 하기

서버가 필요해서 GitHub Pages 같은 정적 호스팅에서는 돌아가지 않습니다.

**같은 와이파이**: 서버를 켠 컴퓨터의 내부 IP로 접속합니다. 예: `http://192.168.0.10:3000`

**인터넷 너머 (EC2 등)**: 항상 켜져 있는 서버에 올립니다.

```bash
# 서버에서
npm install --omit=dev
npm i -g pm2
INVITE_CODE=우리끼리 PORT=3000 pm2 start server/index.js --name golmok
pm2 save
```

보안 그룹에서 TCP 3000번을 열고 `http://서버IP:3000` 으로 접속합니다. 주소가 공개되므로 `INVITE_CODE`는 꼭 설정하세요. 이 방식은 HTTPS가 아니라서 비밀번호가 암호화되지 않습니다. 다른 곳에 쓰는 비밀번호는 쓰지 마세요. HTTPS를 쓰려면 앞에 Nginx나 Caddy를 두거나 Cloudflare Tunnel을 쓰면 됩니다. 프록시에서 WebSocket 업그레이드(`/ws`)를 허용하고 `X-Forwarded-Proto`를 넘겨 주어야 합니다.

**폰만 있을 때 (Render 무료)**: `render.yaml`이 들어 있어서 GitHub 저장소를 Render에 연결하면 바로 뜹니다. 무료 서버는 쉬면 파일이 지워지므로 아래의 `GIST_ID`, `GIST_TOKEN`을 꼭 넣으세요. 15분 동안 접속이 없으면 잠들고, 다음 접속 때 1분쯤 걸려 깨어납니다.

## 설정

| 환경변수 | 기본값 | 설명 |
| --- | --- | --- |
| `PORT` | 3000 | 서버 포트 |
| `INVITE_CODE` | 없음 | 설정하면 계정 만들 때 코드가 필요 |
| `TURN_SECONDS` | 90 | 턴 제한 시간. 넘기면 자동으로 행동 |
| `LEAVE_GRACE_SECONDS` | 15 | 대전 중 연결이 끊긴 뒤 패배 처리까지 기다리는 시간 |
| `DATA_DIR` | `./data` | 계정과 전적이 저장되는 폴더 |
| `GIST_ID` | 없음 | 데이터를 함께 저장할 비밀 Gist의 id |
| `GIST_TOKEN` | 없음 | `gist` 권한만 준 GitHub 토큰 |

계정, 아바타, 팀, 전적은 `data/db.json`에 저장됩니다. 이 폴더를 지우면 전부 사라집니다. 재시작하면 파일이 초기화되는 호스팅에서는 `DATA_DIR`을 영구 디스크로 지정하세요. 진행 중인 대전은 메모리에만 있어서 서버를 재시작하면 사라집니다.

## 덱

계정마다 덱을 개수 제한 없이 만들 수 있습니다. 로비에서 사용할 덱을 고르고 덱의 앞에서부터 대전 인원만큼 나갑니다. 대전이 시작되면 서로의 덱을 보고 먼저 낼 요괴를 고릅니다. 기존 계정의 팀은 `기본 덱`으로 자동 이전됩니다.

## 메가진화

전투 화면의 메가진화 버튼을 누르고 기술을 고르면 변신한 뒤 같은 턴에 공격합니다. 한 판에 한 번만 쓸 수 있고, 변신하면 기본 능력치가 100 오릅니다. 캐릭터별 상승값과 전용기는 `server/data.js`의 `SIGNATURE`에 있습니다.

## 꾸미기

아바타는 3D(three.js, 툰 셰이딩)로 그려지며 22개 항목(머리 모양 20, 눈 12, 모자 14, 옷 14, 체형, 서 있는 자세 12가지(브이, 팔짱, 엄지척, 손하트 등), 바지·신발 색, 장갑, 목걸이, 등 장식, 손 소품, 오라 등)으로 꾸밉니다. 꾸미기 화면에서 아바타를 손가락으로 돌려 보고 동작을 미리 볼 수 있습니다. 1:1 대전에서는 양쪽 트레이너가 필드에 나와 지시, 움찔, 환호 같은 동작을 하고, Z기술을 쓰면 트레이너와 요괴가 같은 안무를 춥니다. WebGL이 안 되는 기기에서는 예전 2D 아바타로 보입니다. 칭호 55개(일반, 반짝, 별가루, 황금, 네온, 전설 6등급으로 나뉘어 어려운 칭호일수록 빛나고 움직이는 효과가 붙음), 전투카드 38개, 핀 70개는 승리, 패배, 무승부, 연승, 골목대장 승리, 태그, 메가진화와 Z기술 사용 기록으로 열립니다. 목록과 조건은 `server/data.js`의 `COSMETICS`에 있습니다.

## Z기술

요괴마다 고유 Z기술이 하나씩 있습니다. 전투 화면의 Z기술 버튼을 누르면 스와이프나 리듬 미션이 나오고, 성공하면 그 턴에 Z기술이 나갑니다. 실패하면 그 턴에는 다시 쓸 수 없습니다. Z기술과 메가진화는 한 판에 각각 한 번씩 쓸 수 있고 같은 턴에 같이 써도 됩니다. Z기술은 PP를 쓰지 않고 반드시 맞으며, 막기를 1/4 위력으로 뚫습니다.

## 태그 2대2와 관전

로비에서 태그 방을 만들고 자리를 고르면 됩니다. 필드에 팀마다 2마리씩 나오는 더블 배틀이고, 각자 덱의 앞 3마리로 싸웁니다. 빈자리는 골목대장 봇이 맡고, 대전 중 나가면 그 자리도 봇이 이어받습니다. 태그 대전은 전적에 반영되지 않습니다.

진행 중인 대전은 로비에서 누구나 관전할 수 있습니다.
